# CharacterBuilder

![The Singularity Workshop moniker](https://raw.githubusercontent.com/TrentBest/TheSingularityWorkshop.Visualize/development/docs/assets/moniker.svg)

## Purpose

CharacterBuilder starts a character with minimal friction. Templates offer optional prompts and suggested traits, but suggestions are not silently converted into established facts.

## UML class card

See [CharacterBuilder UML](../../../docs/UML/CharacterBuilderUML.md) for the class diagram and use case.

## Use case

Call Create when a user opens Casting. The result is a draft. If the user chooses a template, the template determines a broad starting role and makes prompts available; it does not force the user to answer them.
