# SceneComposer

![The Singularity Workshop moniker](https://raw.githubusercontent.com/TrentBest/TheSingularityWorkshop.Visualize/development/docs/assets/moniker.svg)

## Purpose

SceneComposer creates scenes, appends beats, and drafts narration from explicit captured details. It is an authoring aid, not an autonomous storyteller.

## UML class card

See [SceneComposer UML](../../../docs/UML/SceneComposerUML.md) for the class diagram and use case.

## Use case

The host captures the user's action, dialogue, reaction, or pose. ComposeNarration returns an editable draft in sequence order. Missing details remain missing rather than being invented.
