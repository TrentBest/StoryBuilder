# RenderedBookArtifact

![The Singularity Workshop moniker](https://raw.githubusercontent.com/TrentBest/TheSingularityWorkshop.Visualize/development/docs/assets/moniker.svg)

## Purpose

Represents the first deterministic digital book product: Markdown content plus manuscript identity and event-reference metadata. It is a digital composition artifact, not a physical-print layout or immutable published edition.
