# StoryBuilder WebDemo Program

![The Singularity Workshop moniker](https://raw.githubusercontent.com/TrentBest/TheSingularityWorkshop.Visualize/development/docs/assets/moniker.svg)

## Purpose

Program.cs starts an interactive Blazor Server host and registers a StoryBuilderSession created through StoryBuilderAuthoringBundle. The domain and MicroBundle adapters remain reusable by another host.

## Use case

Run the WebDemo project, open the local URL, and use Casting, The Stage, World Archive, and Campaign Room to create and edit real domain records.

## Boundary

This is a local proving ground for authoring interactions. It does not replace WebPage as the Workshop host, and it does not enable publishing or deployment.
