# NarratorPremiseTests

![The Singularity Workshop moniker](https://raw.githubusercontent.com/TrentBest/TheSingularityWorkshop.Visualize/development/docs/assets/moniker.svg)

## Purpose

Verifies that the Narrator's first interaction creates a durable, editable premise proposal without requiring a completed questionnaire. It checks that premise wording enters the shared vocabulary index and that revising the premise removes stale occurrences and indexes the new words.

## Boundary

The current implementation preserves and structures the user's idea. It does not pretend that a local template is an LLM-generated interpretation; richer Narrator dialogue and explicit proposal diffs remain future work.
