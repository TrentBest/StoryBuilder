# ObserverKnowledgeProjectionServiceTests

![The Singularity Workshop moniker](https://raw.githubusercontent.com/TrentBest/TheSingularityWorkshop.Visualize/development/docs/assets/moniker.svg)

## Purpose

Verifies that observer projections include only accepted, causally available knowledge, preserve the allowed narration mode, and omit unrestricted world-event summaries.

## UML class card

See [ObserverKnowledgeProjectionServiceTests UML](../../docs/UML/ObserverKnowledgeProjectionServiceTestsUML.md).

## Acceptance evidence

Tests cover witnessed facts, attributed reports learned at a later causal anchor, hidden events, and proposed knowledge that must not enter a downstream portrayal context.
