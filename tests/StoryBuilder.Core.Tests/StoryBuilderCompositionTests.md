# StoryBuilderCompositionTests

![The Singularity Workshop moniker](https://raw.githubusercontent.com/TrentBest/TheSingularityWorkshop.Visualize/development/docs/assets/moniker.svg)

## Purpose

The test uses the actual FSM_COS package to resolve and load StoryBuilderAuthoringBundle through the MicroBundleDomain contract, then creates a separate authoring session from the composed bundle.

This proves the package boundary and composition path; it does not claim that a clickable UI or persistent storage is already available.
