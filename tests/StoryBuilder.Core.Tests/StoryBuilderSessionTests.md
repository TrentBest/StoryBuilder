# StoryBuilderSessionTests

![The Singularity Workshop moniker](https://raw.githubusercontent.com/TrentBest/TheSingularityWorkshop.Visualize/development/docs/assets/moniker.svg)

## Purpose

These tests verify that creating and editing characters and scenes updates the same workspace-wide vocabulary index. Removing a trait removes its old occurrences; new traits and scene words become searchable.

See [StoryBuilderSession UML](../../docs/UML/StoryBuilderSessionUML.md) for the coordination model.

## Verification

Run the full test project using the repository's Development guide. Passing CI is the evidence that these behaviors work together.
